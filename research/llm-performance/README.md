# FoleyForge 品質向上戦略 解説ドキュメント集

> 4つの品質向上アプローチを、初心者向けに解説したドキュメント集です。
> 各ドキュメントは論文を引用しながら、なぜその手法が効くのかを説明しています。

## このドキュメント集について

FoleyForgeの最大のポイントは、ファインチューニングなしで生成品質を上げる「生成アルゴリズム」にあります。その中核となる4つのアプローチを、それぞれ独立したドキュメントとして解説しました。

各ドキュメントは、前提知識がなくても読めるように書かれています。

## 4つのアプローチの一覧

| # | アプローチ | 一言でいうと | FoleyForgeでの位置付け |
|---|----------|------------|---------------------|
| 1 | LLMによるプロンプト augmentation | 曖昧な入力を良いプロンプトに変換 | 構造化データ設計の土台。採用 |
| 2 | 推論時パラメータの最適化 | CFG等の設定値を用途別に調整 | 戦略ごとのパラメータ制御。採用 |

## 4つのアプローチの関係

これらは独立した手法ではなく、組み合わせて使うことで効果を発揮します。FoleyForgeの処理フローに沿って関係を示すと、以下のようになります。

```
[ユーザ入力（曖昧）]
        ↓
┌──────────────────────────────────┐
│ アプローチ1: プロンプト augmentation│  ← 入力を良いプロンプトに
│ （構造化データ経由）              │
└──────────────────────────────────┘
        ↓
┌──────────────────────────────────┐
│ アプローチ2: 推論時パラメータ最適化 │  ← CFG等を戦略別に設定
└──────────────────────────────────┘
        ↓
┌──────────────────────────────────┐
│ アプローチ3: Best-of-N + リランキング│  ← 大量生成して選別
│ （CLAP + PQ の複数指標）          │
└──────────────────────────────────┘
        ↓
[異なる特性の候補をユーザに提示]


  ── 将来拡張 ──
┌──────────────────────────────────┐
│ アプローチ4: 検索拡張（RAG）       │  ← 珍しい音への対応
└──────────────────────────────────┘
```

## 共通して登場する重要概念

4つのドキュメントを横断して、繰り返し登場する重要な概念があります。

### CLAP（Contrastive Language-Audio Pretraining）

音声とテキストの一致度を数値で測るモデル。アプローチ3（リランキング）とアプローチ4（検索）の両方で中心的な役割を果たします。FoleyForgeの品質評価の土台です。

### トレードオフ（指示追従性 vs 音響的美しさ）

「プロンプト通りか」と「音として美しいか」は、必ずしも両立しません。アプローチ2（CFGのトレードオフ）とアプローチ3（CLAP vs PQ）で、それぞれ別の角度からこの問題が登場します。

### verifier hacking / reward hacking

単一の指標だけを最大化すると、その指標の抜け穴を突いた質の低いものが選ばれてしまう現象。アプローチ3で詳しく扱う、最も重要な落とし穴です。FoleyForgeが複数指標を組み合わせる理由になっています。

### 訓練不要（training-free）

4つのアプローチはいずれも、モデルのファインチューニングを必要としません（アプローチ4の一部を除く）。これはFoleyForgeの「ファインチューニングはしない」という方針と合致しています。

## 読む順番

番号順（1 → 2 → 3 → 4）に読むことを推奨します。アプローチ1で「良いプロンプト」を作り、アプローチ2で「適切な設定」で生成し、アプローチ3で「良いものを選ぶ」という、FoleyForgeの処理フローと同じ順序になっているためです。アプローチ4は発展的な内容なので、最後に読むのが自然です。
