# 設計決定ログ（Decision Log）

> このドキュメントは FoleyForge の「決めたこと」と「その理由」を残す台帳です。
> 進め方の約束事（ラベル・Issue 運用など）は [dev-workflow.md](./dev-workflow.md) を、開発の全体像・方針は [foley-forge-dev.md](./foley-forge-dev.md) を、これから決める／作る未決事項は GitHub Issues を参照してください。

このドキュメントは**追記のみ・上書き禁止**です。決定を見直した場合は、古いエントリを `Superseded` にして新エントリを追記します（運用は dev-workflow.md の「後戻り」を参照）。
